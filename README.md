# 🎨 IconPaq

**IconPaq** – A free, fully responsive icon library with **426 outline icons**, built with **HTML, CSS and Vanilla JavaScript**.
Designed with **clean spacing, live SVG customization, several drawing styles per icon and full dark mode**, perfect for portfolio showcase.

> ⚡ **Portfolio-Level Project** – Showcasing Senior Front-End expertise in **icon system design, live SVG manipulation, themeable design tokens and reusable component structure**.

## ✨ Key Features

- 🔍 **Instant Search** – Typing filters the grid as you go and the result counter follows along
- 🗂 **Category Filter** – One click narrows the library to a single category, and **All Icons** brings the full set back
- 🎛 **Live Customize Panel** – Size, stroke width and color controls that repaint the whole grid in real time
- 🎨 **Smart Recolor** – The palette rewrites every icon path, while genuinely multi color icons keep their own palette
- 🧲 **Style Variants** – Each icon ships several drawing styles, switchable from the strip inside the dialog
- 🔎 **Icon Details Dialog** – Large preview, color picker, the icon name, the raw SVG and the inner component markup
- 📋 **Copy Ready Code** – One click copies the SVG markup or the component markup to the clipboard
- 💾 **Export SVG & PNG** – Download the open icon as clean SVG or as a 4× PNG with a transparent background
- 📦 **Multi Select Mode** – Tick as many icons as you like and export the whole selection in one batch
- 🌗 **Light & Dark Theme** – Follows the system preference on the first visit and remembers your choice afterwards
- 📱 **Fully Responsive** – Three icons per row on phones and a dialog that stacks and scrolls on small screens
- ⚡ **No Build Step** – Plain HTML, CSS and JavaScript with self hosted fonts and self hosted libraries

## 🧩 Project Structure

| Path | Description |
| --- | --- |
| `Assets/css/base.css` | Design tokens, header, footer, buttons, form controls and shared components |
| `Assets/css/index.css` | Icon grid, toolbar, customize panel, multi select pill and the detail dialog |
| `Assets/css/suggest.css` | Request page layout, purple info card and form styling |
| `Assets/css/theme-dark.css` | Dark theme tokens and the few dark only overrides |
| `Assets/sass` | The Sass sources the four stylesheets are compiled from |
| `Assets/js/Custom.js` | Theme, search, filtering, dialog, clipboard, multi select and export |
| `Assets/fonts` | Self-hosted Barlow and Outfit webfonts |
| `Assets/img` | Logo, favicon, hero and form artwork, plus the readme screenshots |
| `Assets/vendor` | Self-hosted Bootstrap, jQuery, Font Awesome and html2canvas |

## ⚙️ How It Works

1. Search by name or pick a category from the sidebar
2. Click an icon to open its detail dialog
3. Flip through the available style variants underneath the preview
4. Set the color, or adjust size and stroke width from the left panel
5. Copy the SVG markup, or download the icon as SVG / PNG
6. Turn on **Multi Select** to collect several icons and export them in one batch
